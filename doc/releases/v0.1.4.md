## 搁置与 Git Stash

- 展开 Shelf 或 Git Stash 条目可查看变更文件，点击文件可在右侧查看只读差异，支持并排和统一视图。
- Shelf 按文件展示保存时的补丁，支持中文及带空格的路径。Git Stash 支持预览一并保存的未跟踪文件。
- 文件列表使用较小字号，超长路径以省略号截断，鼠标悬停可查看完整路径。

## 恢复与冲突解决

- 恢复 Shelf，或应用、弹出 Git Stash 时，可合并同一文件的本地修改。发生冲突后会自动打开解决窗口。
- 可在窗口中逐个解决冲突，并点击“完成冲突解决”完成恢复。恢复后会保留原有暂存内容。
- Pop 发生冲突时保留原 Stash。Shelf 合并了原有未暂存修改且无法安全生成撤销记录时，保留原 Shelf。
