# GitCrest UI/UX 规格

## 1. 体验定位

GitCrest 的界面应像专业工程工具，而不是营销产品。整体风格应高密度、稳定、克制，适合用户连续工作数小时。

核心体验关键词：

- 快速：界面反馈即时，后台任务清晰。
- 清楚：Git 状态、分支、Diff 和风险一眼可见。
- 可控：危险操作有预览、撤销和明确后果。
- 专业：支持键盘、命令面板、多窗口和高信息密度。

## 2. 主窗口

### 2.1 标题栏

内容：

- 应用名称或当前仓库名称。
- 仓库 Tab。
- 新增 Tab 按钮。
- 全局搜索入口。
- 命令面板入口。
- 同步状态。
- 系统窗口控制。

行为：

- Tab 保存每个仓库的选中提交、滚动位置和工作区视图。
- 同步状态显示 fetch/pull/push 后台任务。
- 命令面板快捷键为 `Cmd/Ctrl+K`。

### 2.2 左侧栏

分区：

- 仓库文件树。
- 分支列表。
- Remotes。
- Shelve 列表。

文件树要求：

- 使用 Git 状态颜色。
- 支持按路径搜索。
- 支持按状态过滤。
- 支持右键菜单：打开 Diff、暂存、取消暂存、忽略、复制路径。

分支列表要求：

- 显示当前分支。
- 显示 ahead/behind。
- 收藏分支置顶。
- 远程分支视觉弱于本地分支。

### 2.3 中央提交图

内容：

- 提交节点和分支线。
- 提交标题。
- 作者。
- 相对时间。
- 标签和分支徽标。

交互：

- 点击节点选中提交。
- 双击切换到提交详情。
- 右键打开提交菜单。
- 搜索结果高亮。
- 支持虚拟滚动。

视觉：

- 分支线颜色应稳定且可区分。
- 当前 HEAD 节点更醒目。
- 选中提交使用明显背景和左侧指示线。

### 2.4 右侧详情区

模式：

- 提交详情。
- 文件 Diff 预览。
- 变更摘要。
- Blame 信息。

提交详情内容：

- SHA、作者、提交时间。
- message 标题和正文。
- 父提交和子提交。
- 文件变更列表。
- 操作按钮：复制 SHA、cherry-pick、tag、open diff。

### 2.5 底部工作区

分区：

- 未暂存。
- 已暂存。
- Commit 表单。

工作区行为：

- 拖拽文件到已暂存区等同暂存。
- 点击文件显示 Diff。
- hunk 和行级暂存在 Diff 内完成。
- 提交按钮仅在有暂存内容且 message 有效时启用。

Commit 表单：

- 标题输入。
- 正文折叠区。
- 模板选择。
- AI message 按钮。
- 提交按钮。
- amend 选项。

## 3. Diff 窗口

布局：

- 顶部：文件 Tab、Split/Unified 切换、Blame、搜索。
- 左侧：文件列表。
- 主区域：Diff。
- 底部：行数统计、编码、语言、AI 摘要状态。

Diff 行规则：

- 新增使用绿色背景，删除使用红色背景。
- 修改内容用 token 级高亮。
- 未修改上下文可折叠。
- 语义块显示函数、类、模块名称。

Split 模式：

- 左侧 old，右侧 new。
- 行号对齐。
- 空行占位保持行高一致。

Unified 模式：

- 使用单列展示。
- 行前标记 `+`、`-`、空格。

## 4. 冲突解决窗口

布局：

- 顶部：冲突文件列表和进度。
- 主区域：ours、base、theirs 三列。
- 底部：结果预览。
- 右侧：AI 建议和操作历史。

操作：

- 接受 ours。
- 接受 theirs。
- 手动编辑。
- 逐块合并。
- 标记 resolved。
- 回到主窗口。

安全：

- 结果中仍有冲突标记时，禁用 resolved。
- 关闭窗口不丢弃用户手动编辑，除非用户明确放弃。

## 5. 设置窗口

分区：

- General：启动、最近仓库、默认路径。
- Appearance：主题、字体大小、紧凑模式。
- Shortcuts：快捷键编辑和冲突检测。
- Git：默认 merge/rebase 策略、签名、hooks。
- AI：provider、本地/云端、隐私范围。
- Credentials：SSH、HTTPS token。
- Updates：自动更新、渠道、签名状态。
- Security：危险操作确认策略。

## 6. 空状态

| 场景 | 文案方向 | 主操作 |
|---|---|---|
| 无最近仓库 | 打开或克隆一个仓库开始 | 打开仓库、克隆 |
| 工作区干净 | 当前没有未提交变更 | 查看历史 |
| 搜索无结果 | 没有匹配的提交或文件 | 清除搜索 |
| 无远程 | 当前仓库没有 remote | 添加 remote |
| AI 未配置 | 配置 AI 后可生成建议 | 打开 AI 设置 |

## 7. 响应式和可调整布局

桌面应用优先支持 1280px 以上宽度。低宽度时：

- 左侧栏可折叠。
- 右侧详情区可变为底部抽屉。
- 底部工作区可最大化。
- Diff 窗口保留 Split/Unified，但默认切到 Unified。

所有栏宽可拖拽调整，并保存到仓库级布局状态。
